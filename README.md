# Browser Tetris

A browser-based single-player Tetris project in documentation preparation. No playable implementation is available yet.

See the [project brief](docs/dev/PROJECT.md), [preparation scope and decisions](docs/dev/DOCS_PREPARATION.md), [documentation tasks](docs/dev/DOCS_TASKS.md) and [workflow handoff](docs/dev/HANDOFF.md).

## Development

This repository uses [SDD Manager](SDD-MANAGER.md). See the [AI-assisted development disclosure](AI_DISCLOSURE.md), [agent guidance](AGENTS.md) and [browser development policy](BROWSER_DEV_POLICY.md). Setup and test commands will be documented when implemented and verified.

## Planned delivery

The document set describes six capability increments: classic play, modern gameplay, dynamic ghost visibility, penetrator mode, session configuration and persistent configuration. See [SPEC](docs/dev/SPEC.md), [PLAN](docs/dev/PLAN.md) and the [implementation tasks](docs/dev/TASKS.md). These are planned capabilities; no game implementation has been delivered.
